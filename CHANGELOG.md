# Changelog

## 0.1.0 · Dechub CRM MVP

First internal release of Dechub Cloud with Dechub CRM.

- Login, invites, roles, password reset
- Leads, companies, duplicate detection
- Pipeline board with stage rules
- Lead timeline, notes and contact logs
- Follow-ups, My tasks, overdue badge and team view
- Website form capture with online-user assignment
- CSV import
- Dashboard
- Settings and audit log

## Next (v0.2 ideas)

- Instant WhatsApp or email alerts for new and overdue leads
- Assignment rules by market, workload and working hours
- Meta Lead Ads webhook
- File attachments on Cloudflare R2
- Exports and self-serve erase
